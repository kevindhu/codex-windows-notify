# Notification style lookbook

These are retained design deliverables. Keep the PDF, images, and source.

- Main document: `../pdf/codex-notify-style-lookbook.pdf` (48 pages).
- `previews/`: 108 transparent PNGs, three states for each of 36 concepts.
- `pages/`: all 48 PDF pages rendered as PNGs.
- `page-overview-*.png`: visual contact sheets of the PDF pages.
- `styles.json`: colors, sizes, layouts, and design notes.
- `build_lookbook.py`: reproducible Python renderer and PDF builder.

The images are proposed designs, not captured screenshots of the running app. The app was not changed by this design study.

Rebuild from the repo root with:

```powershell
& 'C:/Users/lemondoo/AppData/Local/Programs/Python/Python311/python.exe' 'output/notification-styles/build_lookbook.py'
```
